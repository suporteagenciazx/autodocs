TRATAMENTO DE DADOS

UTILIZAÇÃO: ÁGUIA ASSESSORIA

A LGPD ESTABELECE QUE OS TITULARES POSSUEM DIREITOS SOBRE OS DADOS PESSOAIS TRATADOS. A ÁGUIA CONSULTORIA EMPRESARIAL POSSUI MEIOS DE COMUNICAÇÃO COM O TITULAR PARA QUE ESSAS SOLICITAÇÕES SEJAM RECEBIDAS, ANALISADAS E ATENDIDAS, SENDO O RESULTADO POSITIVO OU NEGATIVO.

PELA NATUREZA DE NOSSO NEGÓCIO É POSSÍVEL QUE EXISTA O COMPARTILHAMENTO DE DADOS PESSOAIS COM A NOSSA EMPRESA DURANTE O ESTABELECIMENTO DE CONTRATOS DE PRESTAÇÃO DE SERVIÇO COM OS CLIENTES.

COM ISSO, A ÁGUIA CONSULTORIA EMPRESARIAL SEGUE O PAPEL DE OPERADOR DOS DADOS DE ACORDO COM O QUE FOR DETERMINADO PELO CLIENTE QUE ASSUME O PAPEL DE CONTROLADOR DOS DADOS PESSOAIS.

QUANDO HOUVER O COMPARTILHAMENTO PELA ÁGUIA CONSULTORIA EMPRESARIAL COM TERCEIROS, ESTE SERÁ REALIZADO SE FOR ABSOLUTAMENTE NECESSÁRIO PARA O ALCANCE DOS RESULTADOS PARA OS QUAIS ELES SÃO MANTIDOS E QUANDO EXISTIREM ARRANJOS CONTRATUAIS E MECANISMOS DE SEGURANÇA APROPRIADOS.
